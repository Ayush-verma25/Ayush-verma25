### 1️⃣ 🪙 Full-Stack Crypto Tracker App  `🔥 Flagship Project`

<p>
<a href="https://github.com/Ayush-verma25/Full-Stack-Crypto-Tracker-App"><img src="https://img.shields.io/badge/Source%20Code-GitHub-181717?style=for-the-badge&logo=github" alt="Repo"/></a>
<a href="https://full-stack-crypto-tracker-app.vercel.app/"><img src="https://img.shields.io/badge/Live%20Demo-Vercel-000000?style=for-the-badge&logo=vercel" alt="Live"/></a>
<a href="https://full-stack-crypto-tracker-app-server.onrender.com/"><img src="https://img.shields.io/badge/API-Render-46E3B7?style=for-the-badge&logo=render&logoColor=black" alt="API"/></a>
</p>

A **production-deployed, full-stack web application** that displays the **top 10 cryptocurrencies** with **real-time price updates every 3 minutes**, complete with interactive charts and a responsive UI.

**🧰 Tech Stack**

<img src="https://skillicons.dev/icons?i=react,vite,tailwind,nodejs,express,mongodb,vercel&theme=dark" alt="Crypto tracker stack"/>

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React (Vite), Tailwind CSS, Recharts, Lucide React |
| **Backend** | Node.js, Express.js, Axios |
| **Database** | MongoDB |
| **External API** | CoinGecko API |
| **Deployment** | Frontend on **Vercel** • Backend on **Render** |

**✨ Key Features**
- 🔄 Fetches and displays the **top 10 cryptocurrencies** by market ranking
- ⏱️ **Auto-refreshes every 3 minutes** to keep prices current
- 📊 **Interactive charts** and data visualizations powered by Recharts
- 📱 Fully **responsive** UI built with Tailwind CSS
- 🌐 Clean **client / server architecture** with a REST API
- 📁 Modular folder structure (controllers, models, routes, components, pages)

**👨‍💻 My Contribution**
- ✅ Designed and built the **entire application as the sole developer**: frontend, backend and database layer
- ✅ Built a **Node.js + Express REST API** that consumes the CoinGecko API and serves data to the client
- ✅ Implemented **scheduled data refresh logic** for near real-time price updates
- ✅ Created reusable **React components** and data-visualization views with Recharts
- ✅ Configured **separate cloud deployments** (Vercel for the client, Render for the server) with environment-based configuration

### 2️⃣ 🛒 YourCartShop.IO: Angular E-Commerce Storefront

<p>
<a href="https://github.com/Ayush-verma25/YourCartShop-App-Angular"><img src="https://img.shields.io/badge/Source%20Code-GitHub-181717?style=for-the-badge&logo=github" alt="Repo"/></a>
<a href="https://your-cart-shop-app-angular.vercel.app"><img src="https://img.shields.io/badge/Live%20Demo-Vercel-000000?style=for-the-badge&logo=vercel" alt="Live"/></a>
</p>

A **responsive e-commerce storefront** where users can browse categories, filter by sub-category, view product details, manage a shopping cart and place a demo **Cash-on-Delivery** order.

**🧰 Tech Stack**

<img src="https://skillicons.dev/icons?i=angular,ts,bootstrap,rxjs,html,css&theme=dark" alt="YourCartShop stack"/>

`Angular 16.2` • `TypeScript 5.1` • `RxJS 7.8` • `Bootstrap 5.3` • `Bootstrap Icons` • `localStorage` • `Angular CLI`

**✨ Key Features**
- 🏠 Home page with an **auto-playing banner carousel** and category tiles
- 🗂️ **4 product categories** (Fashion, Home & Furniture, Appliances, Toys) with **20 products**
- 🔍 **Sub-category filtering** via dropdown (e.g. Appliances → mobile, smart TV, air cooler, refrigerator)
- 🧾 **Product details page** with pricing in ₹ INR
- 🛍️ **Smart "Add to Cart" button** that switches to "Go to Cart" when an item is already added
- ➕➖ Cart with **quantity controls (1–5)**, item removal and a **live price summary**
- 💾 **Persistent cart** across refreshes using `localStorage`
- ✅ **Order-confirmation modal** (email, address, Cash on Delivery)

**👨‍💻 My Contribution**
- ✅ Architected the full **Angular NgModule application**: routing, services and components
- ✅ Built **route-parameter-driven pages** (`/product-page/:name`, `/product-detail/:name/:id`, `/cart`)
- ✅ Created dedicated **services** for static data (`GetDataService`) and cart persistence (`DataStorageService`)
- ✅ Wrote **comprehensive project documentation** (architecture diagrams, data model, component reference, known limitations and roadmap)
